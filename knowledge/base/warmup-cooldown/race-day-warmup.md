
# Race-day Warm-up / レース当日ウォームアップ

公開配布用テンプレートです。大会名・会場名・選手名は使わず、generic race scenario として扱います。

## Purpose

- Race start 時に体温、水感、神経系を適切な状態にする。
- Race pace primer（レースペース刺激）を少量入れ、疲労を残さない。
- レース 15〜25 分前に水中 warm-up を終えることを目安にする。

## Standard 800〜1000m

| Block | Set | Intensity | Purpose |
|---|---|---|---|
| Easy swim | 300〜400m Free/Back mix | EN1 | 体を温める |
| Drill | 4 × 50m drill/swim by 25m | EN1 | 今日の泳法感覚 |
| Kick | 4 × 25m kick build | EN1→EN2 | 脚を起こす |
| Build | 4 × 50m descend | EN2→race feel | tempo 確認 |
| Primer | 2〜4 × 25m at race pace, full rest | SP2〜SP3 touch | レース速度を短く確認 |
| Easy | 100〜200m easy | EN1 | 呼吸を整える |

## Short pool-availability version 600m

| Block | Set | Intensity |
|---|---|---|
| Swim | 300m easy mixed | EN1 |
| Drill | 4 × 25m drill/swim | EN1 |
| Build | 4 × 25m build | EN2 touch |
| Primer | 2 × 25m race pace | SP2〜SP3 touch |
| Easy | 100m easy | EN1 |

## Long version 1000〜1200m

| Block | Set | Intensity |
|---|---|---|
| Swim | 500m easy mixed | EN1 |
| Drill/Kick | 6 × 50m as drill/kick/swim rotation | EN1〜EN2 |
| Build | 4 × 50m descend | EN2→race feel |
| Primer | 4 × 25m race pace, full rest | SP2〜SP3 touch |
| Easy | 200m easy | EN1 |

## Timing guide

| Time before race | Action |
|---|---|
| 60〜45 min | Dry mobility and check equipment |
| 45〜25 min | Water warm-up if pool is available |
| 25〜15 min | Finish water work; keep warm |
| 15〜5 min | Light dry activation, calm breathing |
| <5 min | No extra fatigue; stay ready |

## Pool availability considerations

- 混雑している場合、dive や all-out sprint は避けます。
- 25m race pace は安全な方向・間隔で実施します。
- サブプールがない場合は dry warm-up を厚めにし、水中は 400〜600m に圧縮します。
- Lane rule が不明な場合は easy swim と build のみにします。

## Coach notes

- Race pace primer は『疲れる練習』ではありません。
- 不安で距離を増やしすぎる選手には、いつもの固定 routine を用意します。
- Phase D (taper) では短く高品質にし、EN3 以上を長く続けません。
- 体が冷えやすい環境では towel, clothing, dry mobility で保温します。

## Coach observation prompts

- Is the swimmer moving more smoothly after the first 200m?
- Is breathing calm enough to progress toward the next block?
- Are shoulders, hips, and ankles warming without forced range of motion?
- Does the selected template match the main set intensity?
- Is the group ready to start the main set without hidden fatigue?

## Modification recipes

| Constraint | Adjustment |
|---|---|
| Limited pool time | Keep easy swim + build, reduce drill volume first. |
| Crowded lane | Avoid sprint and complex drill; use continuous easy swimming. |
| Cold environment | Add easy swimming and dry clothing after exit. |
| High-intensity main | Preserve primer quality and do not rush the first fast repeat. |
| Recovery day | Remove race-pace work and keep all movement EN1. |

## Privacy and publication guardrails

- Do not record real athlete names, real facility names, medical details, or private notes.
- Use placeholders such as `masters group A`, `junior group B`, and `local pool SCM`.
- Keep public templates coach-agnostic; custom notes belong under `knowledge/custom/`.

## Quick coach script

1. State the purpose of this block in one sentence.
2. Give one technical cue only.
3. Let the group complete the first repeat smoothly.
4. Adjust distance or rest if mechanics drop.
5. Finish with EN1 movement unless the next block requires immediate quality.

## Last-minute simplification

- If the warm-up pool closes early, keep 300m easy + 4 × 25m build + 100m easy.
- If the swimmer feels flat, add one relaxed 25m at race rhythm rather than more volume.
- If the swimmer feels over-aroused, remove the final primer and extend easy swimming.
- Always prioritize safety, lane rules, and calm execution over completing every line of the template.
