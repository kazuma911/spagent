
# Standard Warm-up / 標準ウォームアップ

公開配布用テンプレートです。個人名・施設名・実在チーム名は含めません。Phase / Zone は `../../references/zone-phase-mapping.md` を参照します。

## Purpose

- 体温と水感を上げる。
- 肩・股関節・体幹を急に高強度へ入れない。
- Swim / Kick / Drill / Build を短く通し、main set へ接続する。
- coach と swimmer が同じ cue を共有してから本練習へ入る。

## Template 1: Short 400m（約10分）

| Block | Set | Intensity | Coach cue |
|---|---|---|---|
| Swim | 200m easy Free/Back | EN1 | 呼吸を落ち着け、長い姿勢 |
| Kick | 4 × 25m kick @ easy | EN1 | 小さく連続、腰を沈めない |
| Drill | 4 × 25m drill/swim by 12.5m | EN1 | 今日の技術テーマ1つ |
| Build | 4 × 25m build 1〜4 | EN1→EN2/EN3 touch | 力まず少しずつ上げる |

**When to pick**

- 短時間セッション。
- Recovery day の前半。
- Junior group B など集中時間を短くしたい場合。
- Main set が軽い aerobic または technique の日。

## Template 2: Medium 600m（約15分）

| Block | Set | Intensity | Coach cue |
|---|---|---|---|
| Swim | 300m easy as 100 Free / 100 Back / 100 choice | EN1 | 体をほぐす |
| Kick | 4 × 50m kick @ moderate easy | EN1〜EN2 | 姿勢優先 |
| Drill | 4 × 50m drill/swim by 25m | EN1 | メインに関連する drill |
| Build | 4 × 25m build + 100m easy | EN2 touch | 呼吸と tempo を整える |

**When to pick**

- 一般的な平日練習。
- Threshold (閾値) や Endurance 前。
- masters group A の標準導入。
- Pool traffic が中程度で 50m drill を安全に行える日。

## Template 3: Long 800m（約20分）

| Block | Set | Intensity | Coach cue |
|---|---|---|---|
| Swim | 400m easy mixed | EN1 | 大きな動きで温める |
| Kick | 4 × 50m kick | EN1〜EN2 | 脚と体幹を起こす |
| Drill | 6 × 50m drill/swim | EN1 | 水感と姿勢 |
| Build | 4 × 50m descend 1〜4 | EN2→EN3 touch | メイン速度へ接続 |

**When to pick**

- VO2max / Sprint など高強度前。
- 朝一番や水温が低いなど、体が温まりにくい日。
- elite group の quality session。
- Race simulation の前半。

## Selection table

| Session type | Recommended warm-up | Reason |
|---|---|---|
| Recovery | Short 400m | 疲労を増やさず水感を作る |
| EN2 endurance | Medium 600m | 十分な準備と時間効率の balance |
| EN3 threshold | Medium〜Long | 心拍を段階的に上げる |
| SP1 VO2max | Long 800m | 高強度前に体を十分温める |
| SP2-SP3 sprint | Long 800m + primer | 神経系 activation が必要 |

## Coach notes

- Warm-up で疲れさせない。目的は preparation です。
- Build は sprint ではなく progressive swim にします。
- 肩に違和感がある場合は pull/paddle を避け、Back や drill を増やします。
- 混雑時は 25m drill を減らし continuous swim に寄せます。
- cue は1〜2個に絞り、main set 中も同じ言葉で観察します。

## Coach observation prompts

- Is the swimmer moving more smoothly after the first 200m?
- Is breathing calm enough to progress toward the next block?
- Are shoulders, hips, and ankles warming without forced range of motion?
- Does the selected template match the main set intensity?
- Is the group ready to start the main set without hidden fatigue?

## Modification recipes

| Constraint | Adjustment |
|---|---|
| Limited pool time | Keep easy swim + build, reduce drill volume first. |
| Crowded lane | Avoid sprint and complex drill; use continuous easy swimming. |
| Cold environment | Add easy swimming and dry clothing after exit. |
| High-intensity main | Preserve primer quality and do not rush the first fast repeat. |
| Recovery day | Remove race-pace work and keep all movement EN1. |

## Privacy and publication guardrails

- Do not record real athlete names, real facility names, medical details, or private notes.
- Use placeholders such as `masters group A`, `junior group B`, and `local pool SCM`.
- Keep public templates coach-agnostic; custom notes belong under `knowledge/custom/`.

## Quick coach script

1. State the purpose of this block in one sentence.
2. Give one technical cue only.
3. Let the group complete the first repeat smoothly.
4. Adjust distance or rest if mechanics drop.
5. Finish with EN1 movement unless the next block requires immediate quality.
