# Integrated Phase-B Warm-up / Phase-B 統合ウォームアップ

公開配布用のウォームアップ パターンです。個人名・実在施設名・日付は含めません。Coach-agnostic template として利用します。

## Summary

| 項目 | 内容 |
|---|---|
| Applicable Phase | B〜D (特に race-pace / broken / USRPT の main を控えた日) |
| Total distance | 1000〜1200m |
| Duration | 20〜25 min |
| Pattern name | Choice + Drill + IM-mix + AP (Abdominal-Pressure) 統合型 W-up |
| References | `../references/menu-design.md`, `../main-menus/race-pace/*.md` |

## Background

Race-pace 系メニュー (USRPT / Hard-Easy / Broken) の直前に、単なる有酸素 W-up だけでなく **技術要素 + 種目マルチ + 神経系スイッチ** を含めた統合型 W-up。「main のときにだけ race pace 感覚を作る」のではなく、W-up の段階から race-specific な要素を織り込みます。

## Set structure

| Block | Set | Intensity / Cycle | Target purpose |
|---|---|---|---|
| Continuous | 1 × 400m Choice easy | EN1 | 有酸素立ち上げ |
| Drill | 6 × 50m rotating drills | Technique | 技術要素 |
| IM-mix | 6 × 50m as Fly/Fr/Ba/Fr/Br/Fr (moderate) | EN2 | 種目マルチ準備 |
| AP switch | 1 × 100m as 25m drill / 25m swim × 2, focus on abdominal pressure | Neural | 神経系スイッチ |

## Execution steps

1. 400m Choice easy はスイマーが自分でストローク / キック / breathing を選択、DPS (distance per stroke) 一定を目標にします。
2. Drill 6 × 50m は phase-B 標準セット (下記の drill 順) を回します。Fins は任意 (3-5 番目のみ着けるコーチも)。
3. IM-mix は「moderate」で 4 種目に触れる。Fly の 50m は完全に easy でよく、負荷ではなく neural priming です。
4. AP (Abdominal Pressure) は腹圧を意識した drill-swim mix。片手キック → 板キック の 2 バリエーションを組み合わせます。
5. AP 100 の後に main へ入るため、rest 1 分程度で切り替えます。

## Drill rotation (recommended)

| # | Drill | Cue |
|---|---|---|
| 1 | Scull (前方 sculling) | 前腕で水を捉える |
| 2 | Single Arm 2-beat right | 右腕主体 + 呼吸左向き |
| 3 | Single Arm 2-beat left | 左腕主体 + 呼吸右向き |
| 4 | Fingertip drag | ハイエルボー |
| 5 | Catch-up | 前伸び完了までパルス待つ |
| 6 | Swim w/ cues | 全習 (最後の 1 本で cue 統合) |

## Coach notes

- W-up が長すぎると main の質が落ちます。**総距離 1100m 以内、時間 22 分以内が目安**。
- IM-mix の Fly は必ず「軽く」入る。ここでガチった選手は main の race-pace で崩れます。
- AP セットは「腹圧を意識する」cue が中心。フォーム完璧を要求しないこと。

## Variants

- **Short-course**: 全 50m 単位で drill / IM-mix。turn の練習を drill 5-6 番目で兼ねる。
- **Long-course**: 50m LCM は turn なしで stroke length 要求が高い。drill を 100m 単位 (25 drill + 25 swim × 2) に変更可。
- **Junior-friendly**: 400m Choice を 200m に、drill を 4 × 50m に短縮。AP は skip。

## Scaling guide

| Group | Adjustment |
|---|---|
| masters group A | 標準 1100m / 22 分。fins optional。 |
| junior group B | 800m / 18 分。IM-mix は Fly/Fr のみ 4 × 50m に。 |
| elite group | 1200m / 25 分。AP を 200m (100m × 2 バリエーション) に拡張可。 |
| triathlon group | Freestyle 中心、IM-mix skip、drill を Fr のみに変更。 |
| mixed/any | Choice を全員自由に、drill / IM-mix は共通 cue で。 |

## When to avoid

- Recovery セッション (main が低強度なら通常 W-up 500〜700m で十分)。
- Race-pace ではないメニュー (Threshold / VO2max なら別の W-up テンプレを推奨)。
- Warm-up 時間が 15 分以下しか取れない日 (AP を skip、drill を 3 × 50 に短縮)。

## Quality checklist

- 総距離 1000〜1200m の範囲内。
- Fly の 50m が完全 easy で入っている。
- Drill 順序が固定されている (毎回同じ)。
- AP セットが省略されていない (race-pace 前は特に)。
- 個人名、施設名、医療・体調詳細などの PII を記録しない。

## Modification recipes

| Need | Modification |
|---|---|
| Lower total distance | AP を 100 → 50、Drill 6 → 4 に。 |
| Race-day version | 400m を 200m に短縮、Drill 3 本、IM-mix skip、AP 100m のみ (全 500m)。 |
| Recovery day | 全体を 700m に、AP と IM-mix を skip、Choice のみ。 |
| Junior / beginner | Drill を 4 × 50m に、cue を 1 つに絞る。 |

## Privacy and publication guardrails

- Do not add swimmer names, real facility names, medical details, or private notes.
- Use placeholders such as `masters group A`, `junior group B`, or `local pool SCM`.
- If importing a real past menu, sanitize it before merging into public base knowledge.
