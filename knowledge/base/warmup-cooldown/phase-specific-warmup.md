
# Phase-specific Warm-up / Phase別ウォームアップ調整

Phase / Zone の定義は `../../references/zone-phase-mapping.md` と `../../references/phase-method-mapping.md` を参照します。

## Overview

| Phase | Warm-up character | Typical volume | Key point |
|---|---|---:|---|
| A 基礎形成 | Longer easy | 600〜1000m | 可動域・姿勢・水感 |
| B ビルド | Standard + short primer | 600〜900m | メイン強度へ段階接続 |
| C レース特異 | Focused primer + speed activation | 700〜1000m | レース動作の再現 |
| D テーパー | Short high-quality primer | 400〜800m | 疲労を残さず感覚を上げる |

## Phase A: Longer easy

| Block | Example | Intensity |
|---|---|---|
| Easy swim | 400m mixed | EN1 |
| Kick | 4 × 50m posture kick | EN1 |
| Drill | 6 × 50m drill/swim | EN1 |
| Build | 4 × 25m smooth build | EN2 touch |

**Coach notes**

- 急いで強度を上げず、動作品質を整えます。
- Drill の説明時間を確保してもよい Phase です。
- 長めの easy swim で肩と股関節を自然に温めます。

## Phase B: Standard + short primer

| Block | Example | Intensity |
|---|---|---|
| Easy swim | 300m | EN1 |
| Drill/Kick | 6 × 50m | EN1〜EN2 |
| Build | 4 × 50m descend | EN2→EN3 touch |
| Primer | 2 × 25m target tempo | Main-zone touch |

**Coach notes**

- Threshold や Endurance の前は、長すぎる sprint を入れません。
- Main の Zone に一度触れる程度で十分です。
- Primer は成功体験で終え、疲労を持ち込まないようにします。

## Phase C: Focused primer + speed activation

| Block | Example | Intensity |
|---|---|---|
| Easy swim | 300〜400m | EN1 |
| Stroke drill | 4 × 50m | EN1 |
| Build | 4 × 25m build | EN2→SP1 touch |
| Speed primer | 2〜4 × 25m race pace, full rest | SP2〜SP3 touch |
| Easy reset | 100m | EN1 |

**Coach notes**

- 高強度前は primer の質を上げ、量は抑えます。
- Starts / turns / breakouts を入れる場合は 2〜4本で十分です。
- Main set の race skill と同じ cue を warm-up から使います。

## Phase D: Short high-quality primer

| Block | Example | Intensity |
|---|---|---|
| Easy swim | 200〜300m | EN1 |
| Drill | 4 × 25m | EN1 |
| Build | 4 × 25m | EN2 touch |
| Race feel | 2 × 25m race pace, full rest | SP2 touch |
| Easy | 100m | EN1 |

**Coach notes**

- 体を重くする量は避けます。
- 『足りない不安』で増やすより、良い感覚で終えることを優先します。
- Taper 中の warm-up は毎回大きく変えず、再現性を重視します。

## Quick selection checklist

- Main set が EN2 以下なら primer は短くします。
- Main set が SP1 以上なら warm-up を省略しません。
- 技術修正が目的なら drill を多めに、race day は cue を少なくします。
- Group 内の差が大きい場合、距離ではなく時間で合わせます。

## Coach observation prompts

- Is the swimmer moving more smoothly after the first 200m?
- Is breathing calm enough to progress toward the next block?
- Are shoulders, hips, and ankles warming without forced range of motion?
- Does the selected template match the main set intensity?
- Is the group ready to start the main set without hidden fatigue?

## Modification recipes

| Constraint | Adjustment |
|---|---|
| Limited pool time | Keep easy swim + build, reduce drill volume first. |
| Crowded lane | Avoid sprint and complex drill; use continuous easy swimming. |
| Cold environment | Add easy swimming and dry clothing after exit. |
| High-intensity main | Preserve primer quality and do not rush the first fast repeat. |
| Recovery day | Remove race-pace work and keep all movement EN1. |

## Privacy and publication guardrails

- Do not record real athlete names, real facility names, medical details, or private notes.
- Use placeholders such as `masters group A`, `junior group B`, and `local pool SCM`.
- Keep public templates coach-agnostic; custom notes belong under `knowledge/custom/`.

## Quick coach script

1. State the purpose of this block in one sentence.
2. Give one technical cue only.
3. Let the group complete the first repeat smoothly.
4. Adjust distance or rest if mechanics drop.
5. Finish with EN1 movement unless the next block requires immediate quality.
