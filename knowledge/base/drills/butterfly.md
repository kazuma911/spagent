# Butterfly Drills / バタフライドリル

公開配布用のドリルナレッジです。個人名・実在施設名・PII は含めず、`masters group A` や `local pool SCM` のような一般表現だけを使います。

## 参照

- Phase / Zone: `../../references/zone-phase-mapping.md`
- Menu design: `../../references/menu-design.md`
- Drill は良い動作を保てる距離で止め、疲労した反復を増やしません。

## Phase 適用度（共通ガイド）

| Phase | 適用度 | 使い方 |
|---|---:|---|
| A 基礎形成 | ◎ | 低強度で反復し、動作の土台を作る |
| B ビルド | ◎ | Drill + Swim でメインセットへ接続する |
| C レース特異 | ○ | 短距離・高品質でレース動作へ転移する |
| D テーパー | △〜◎ | 疲労を残さない量で感覚確認に使う |

## Coach implementation guide

| 場面 | 入れ方 | 例 |
|---|---|---|
| Warm-up 後 | 25m 単位で導入 | 4 × 25m drill @ easy |
| Pre-main | Drill/Swim で接続 | 6 × 50m drill/swim by 25m |
| Technique day | 低強度で反復 | 8 × 50m, 1 cue only |
| Taper | 少量・高品質 | 4 × 25m, full rest |

## Drill collection

### 1. Single Arm Fly / 片手バタフライ

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | timing、片側 catch、呼吸時の安定。 |
| Description（実施方法・距離目安） | 片腕 fly、反対腕は前方または体側。25m×左右。 |
| Recommended phase / applicability | A/B ◎、C ○、D △。基本 drill。 |
| Alternative names / variants | One-arm fly |

**Focus points（Coach cues）**

- 胸を前下方へ
- 呼吸は低く前へ
- 2 kick rhythm

**Common mistakes**

- 水を下へ押す
- 膝曲げ kick
- 頭が残る

**Coach use / progression**

- 12.5m から始め、良い動作だけ反復。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

### 2. 3-3-3 Fly / 3-3-3バタフライ

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | 左右差と通常泳への接続。 |
| Description（実施方法・距離目安） | 右3、左3、両手3 stroke。25〜50m。 |
| Recommended phase / applicability | A/B ◎、C ○、D △。接続練習。 |
| Alternative names / variants | 2-2-2, 4-4-4 |

**Focus points（Coach cues）**

- 同じ体幹 rhythm
- 両手で力まない
- 呼吸回数を制御

**Common mistakes**

- 両手で急ぐ
- 体がねじれる
- 第2kickが消える

**Coach use / progression**

- 短い単位でバタフライを導入できます。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

### 3. 1-Arm 1-Full / 片手1回＋両手1回

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | drill から swim へ自然に転移。 |
| Description（実施方法・距離目安） | 片手1回の後に両手1回。25m。 |
| Recommended phase / applicability | B ◎、C ○、D △。フォーム接続。 |
| Alternative names / variants | Alternating one-arm/full |

**Focus points（Coach cues）**

- 胸の波を維持
- 前へ長く
- 呼吸は必要分だけ

**Common mistakes**

- 両手で力む
- 呼吸が遅れる
- kick timing が変わる

**Coach use / progression**

- Main 前の 4×25m に向きます。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

### 4. Body Dolphin / ボディドルフィン

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | 胸・体幹・腰からの波動。 |
| Description（実施方法・距離目安） | 腕は前方または体側、全身の波で進む。25m。 |
| Recommended phase / applicability | A/B ◎、C ○、D ○。基礎。 |
| Alternative names / variants | Dolphin kick on front |

**Focus points（Coach cues）**

- 胸から波を作る
- 膝から蹴らない
- 前へ進む波

**Common mistakes**

- 膝kickだけ
- 頭が上下する
- 腰を反る

**Coach use / progression**

- フィンで成功感を作り、ノーフィンは短距離。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

### 5. No Breath Fly / ノーブレスバタフライ

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | 呼吸で崩れる頭位置。 |
| Description（実施方法・距離目安） | 12.5〜25m 呼吸なし、十分休息。 |
| Recommended phase / applicability | B ○、C ◎、D ○。短距離限定。 |
| Alternative names / variants | Low-breath contrast |

**Focus points（Coach cues）**

- 頭を低く
- 短距離で速く
- 息こらえを競わない

**Common mistakes**

- 低酸素になる
- 肩が力む
- 通常泳で頭が高い

**Coach use / progression**

- 姿勢確認が目的で、呼吸制限練習ではありません。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

### 6. Dolphin Kick on Back / 背面ドルフィンキック

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | 体幹と kick 連動、腰位置。 |
| Description（実施方法・距離目安） | 背面 streamline で dolphin kick。25m。 |
| Recommended phase / applicability | A/B ◎、C ○、D ○。水中姿勢へ接続。 |
| Alternative names / variants | Back dolphin |

**Focus points（Coach cues）**

- 肋骨を締める
- 小さく連続
- 水面を叩かない

**Common mistakes**

- 膝が大きい
- 上半身が固い
- 腕が開く

**Coach use / progression**

- Start/turn 後の underwater dolphin 導入に使います。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

### 7. Butterfly Scull to Pull / バタフライスカーリング〜プル

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | 両手 catch の幅と圧。 |
| Description（実施方法・距離目安） | 前方 scull から小さな fly pull。25m。 |
| Recommended phase / applicability | A/B ◎、C ○、D ◎。水感確認。 |
| Alternative names / variants | Front scull fly |

**Focus points（Coach cues）**

- 肩幅より少し広く
- 肘を落とさない
- 胸の波と合わせる

**Common mistakes**

- 手が広すぎる
- 下へ押す
- 泡を掴む

**Coach use / progression**

- 12.5m scull + 12.5m swim が有効。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

### 8. Kick-Kick-Pull / キック・キック・プル

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | 2 kick の役割と pull timing。 |
| Description（実施方法・距離目安） | 第1kickで前方移動、第2kickで pull 後半補助。25m。 |
| Recommended phase / applicability | A/B ◎、C ○、D △。timing 学習。 |
| Alternative names / variants | 2-kick fly drill |

**Focus points（Coach cues）**

- 1kick目は前へ
- 呼吸は低く
- kick 間隔を一定

**Common mistakes**

- 2kick目が消える
- 膝を大きく曲げる
- pull が遅れる

**Coach use / progression**

- 通常泳と交互にして速度への影響を確認。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

## セットへの組み込み例

- Butterfly は疲労で崩れやすいため短距離・十分休息。
- D期は Body Dolphin や Scull の少量確認が中心。

## Safety / operation

- 痛み、めまい、過呼吸が出る場合は中止します。
- 呼吸制限や水中動作は監視可能な範囲と十分な休息を前提にします。
- ドリル名は標準用語として扱い、選手固有のメモは custom knowledge に分離します。
