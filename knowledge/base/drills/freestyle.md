# Freestyle Drills / クロールドリル

公開配布用のドリルナレッジです。個人名・実在施設名・PII は含めず、`masters group A` や `local pool SCM` のような一般表現だけを使います。

## 参照

- Phase / Zone: `../../references/zone-phase-mapping.md`
- Menu design: `../../references/menu-design.md`
- Drill は良い動作を保てる距離で止め、疲労した反復を増やしません。

## Phase 適用度（共通ガイド）

| Phase | 適用度 | 使い方 |
|---|---:|---|
| A 基礎形成 | ◎ | 低強度で反復し、動作の土台を作る |
| B ビルド | ◎ | Drill + Swim でメインセットへ接続する |
| C レース特異 | ○ | 短距離・高品質でレース動作へ転移する |
| D テーパー | △〜◎ | 疲労を残さない量で感覚確認に使う |

## Coach implementation guide

| 場面 | 入れ方 | 例 |
|---|---|---|
| Warm-up 後 | 25m 単位で導入 | 4 × 25m drill @ easy |
| Pre-main | Drill/Swim で接続 | 6 × 50m drill/swim by 25m |
| Technique day | 低強度で反復 | 8 × 50m, 1 cue only |
| Taper | 少量・高品質 | 4 × 25m, full rest |

## Drill collection

### 1. Catch-up / キャッチアップ

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | 左右タイミングが早すぎる、前方支持が抜ける課題。 |
| Description（実施方法・距離目安） | 片手を前で待たせ、反対手が戻ってから次の stroke。25〜50m。 |
| Recommended phase / applicability | A/B ◎、C ○、D △。front-quadrant 確認に有効。 |
| Alternative names / variants | Front-quadrant swim, board catch-up |

**Focus points（Coach cues）**

- 前の手で水を軽く押さえる
- 入水は肩幅、中心線を越えない
- 呼吸しても前の手を沈めない

**Common mistakes**

- 完全停止してリズムが消える
- 手が内側に入り蛇行する
- 呼吸で頭が上がる

**Coach use / progression**

- 初心者は分解、上級者は前方支持の感覚確認として使います。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

### 2. Fingertip Drag / フィンガーチップドラッグ

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | リカバリーで肩が力む、肘が落ちる課題。 |
| Description（実施方法・距離目安） | 指先で水面をなぞりながら戻す。25〜50m。 |
| Recommended phase / applicability | A/B ◎、C ○、D ○。肩の温めにも使える。 |
| Alternative names / variants | Zipper, thumb drag |

**Focus points（Coach cues）**

- 肘を高く前腕は脱力
- ローリングとリカバリーを同期
- 指先は軽く触るだけ

**Common mistakes**

- 肩をすくめる
- 入水が内側に寄る
- 腕だけで戻す

**Coach use / progression**

- 肩違和感があれば軌道を広げるか別 drill にします。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

### 3. Single Arm Free / 片手クロール

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | 片側キャッチ、呼吸、ローリングの左右差。 |
| Description（実施方法・距離目安） | 片腕のみで泳ぎ、反対腕は前方または体側。25m×左右。 |
| Recommended phase / applicability | A/B ◎、C ○、D △。左右差修正に有効。 |
| Alternative names / variants | Arm front, arm at side, snorkel |

**Focus points（Coach cues）**

- 頭の軸を残す
- 肘を少し高く保つ
- キックで体幹を支える

**Common mistakes**

- 蛇行する
- 前方腕が落ちる
- 体側固定で腰が沈む

**Coach use / progression**

- 左右同量から始め、苦手側は短距離で成功を作ります。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

### 4. 6-Kick 1-Pull / 6キック1プル

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | サイドバランス、ローリング、呼吸位置。 |
| Description（実施方法・距離目安） | 片側で6キック、1 stroke で反対側へ切替。25〜50m。 |
| Recommended phase / applicability | A/B ◎、C ○、D △。姿勢作りに強い。 |
| Alternative names / variants | 6-1-6, 3-kick switch |

**Focus points（Coach cues）**

- 下の肩を前へ伸ばす
- 切替は腰から
- 目線は横〜斜め下

**Common mistakes**

- 膝曲げキック
- 頭が左右に振れる
- 下の腕が沈む

**Coach use / progression**

- フィンで姿勢を成功させてからノーフィンへ戻します。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

### 5. Zipper Drill / ジッパードリル

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | リカバリー軌道と肘の高さ。 |
| Description（実施方法・距離目安） | 親指を体側のジッパーに沿わせる意識で戻す。25m。 |
| Recommended phase / applicability | A/B ○、C △、D △。肩可動域に注意。 |
| Alternative names / variants | Thumb drag, armpit touch |

**Focus points（Coach cues）**

- 肘から先行
- 入水は肩の延長
- 肩が詰まれば広げる

**Common mistakes**

- 内旋しすぎる
- 肘が後ろに残る
- 入水が内側

**Coach use / progression**

- 痛みがある場合は fingertip drag に変更します。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

### 6. Fist Swim / グースイム

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | 前腕で水を捉える感覚。 |
| Description（実施方法・距離目安） | 拳を握って泳ぎ、25m fist + 25m open hand で比較。 |
| Recommended phase / applicability | A/B ◎、C ○、D ○。水感作りに有効。 |
| Alternative names / variants | Half-fist, tennis ball swim |

**Focus points（Coach cues）**

- 前腕全体に圧を感じる
- 姿勢を保つ
- open hand の水感を覚える

**Common mistakes**

- 肘が落ちる
- 肩に力が入る
- キックでごまかす

**Coach use / progression**

- Threshold 前のキャッチ準備として使いやすいです。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

### 7. Head-Up Free / 顔上げクロール

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | 前方確認、短い強いキャッチ、open-water skill。 |
| Description（実施方法・距離目安） | 目線を前にして12.5〜25m、十分休息。 |
| Recommended phase / applicability | B ○、C ◎、D ○。短い速度刺激に。 |
| Alternative names / variants | Tarzan swim, sighting free |

**Focus points（Coach cues）**

- 短く強いキャッチ
- 腰を落とさない
- 距離は短く

**Common mistakes**

- 首を反らせすぎる
- 腕だけで急ぐ
- 長くやりすぎる

**Coach use / progression**

- 通常泳へ 12.5m + 12.5m で接続します。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

### 9. High Elbow Catch Drill / ハイエルボーキャッチ

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | キャッチで肘が落ち、下へ押す課題。 |
| Description（実施方法・距離目安） | 入水後に前腕を立てる動きをゆっくり確認。25m drill + swim。 |
| Recommended phase / applicability | A/B ◎、C ○、D △。低速で正確に。 |
| Alternative names / variants | EVF drill, dog-paddle |

**Focus points（Coach cues）**

- 肘を前に残す
- 指先を下へ
- 水を後ろへ押す

**Common mistakes**

- 肩が詰まる
- 手首だけ曲げる
- 下へ押して上下動

**Coach use / progression**

- 小型パドルは短時間のみ。肩痛があれば使いません。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

### 10. Bilateral Breathing / 左右呼吸

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | 呼吸左右差とローリング偏り。 |
| Description（実施方法・距離目安） | 3回に1回、または25mごと左右交互。50〜100m。 |
| Recommended phase / applicability | A/B ◎、C ○、D △。技術練習として使用。 |
| Alternative names / variants | 3/5 breathing, left-only/right-only |

**Focus points（Coach cues）**

- 水中で細く吐く
- 肩だけ上げない
- 苦手側は速度を落とす

**Common mistakes**

- 低酸素になる
- 顔を前に上げる
- レースペースで強制する

**Coach use / progression**

- 選択肢を増やす目的で使い、レース戦略とは分けます。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

## セットへの組み込み例

- Fist Swim → High Elbow Catch → Threshold main の接続が有効。
- Sprint 前は Head-Up Free を短く使い、疲労を残しません。

## Safety / operation

- 痛み、めまい、過呼吸が出る場合は中止します。
- 呼吸制限や水中動作は監視可能な範囲と十分な休息を前提にします。
- ドリル名は標準用語として扱い、選手固有のメモは custom knowledge に分離します。
