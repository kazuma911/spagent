# Backstroke Drills / 背泳ぎドリル

公開配布用のドリルナレッジです。個人名・実在施設名・PII は含めず、`masters group A` や `local pool SCM` のような一般表現だけを使います。

## 参照

- Phase / Zone: `../../references/zone-phase-mapping.md`
- Menu design: `../../references/menu-design.md`
- Drill は良い動作を保てる距離で止め、疲労した反復を増やしません。

## Phase 適用度（共通ガイド）

| Phase | 適用度 | 使い方 |
|---|---:|---|
| A 基礎形成 | ◎ | 低強度で反復し、動作の土台を作る |
| B ビルド | ◎ | Drill + Swim でメインセットへ接続する |
| C レース特異 | ○ | 短距離・高品質でレース動作へ転移する |
| D テーパー | △〜◎ | 疲労を残さない量で感覚確認に使う |

## Coach implementation guide

| 場面 | 入れ方 | 例 |
|---|---|---|
| Warm-up 後 | 25m 単位で導入 | 4 × 25m drill @ easy |
| Pre-main | Drill/Swim で接続 | 6 × 50m drill/swim by 25m |
| Technique day | 低強度で反復 | 8 × 50m, 1 cue only |
| Taper | 少量・高品質 | 4 × 25m, full rest |

## Drill collection

### 1. Double Arm Back / 両手背泳ぎ

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | 左右同時のキャッチ、胸郭の開き。 |
| Description（実施方法・距離目安） | 両腕同時リカバリー・同時キャッチ。25〜50m。 |
| Recommended phase / applicability | A/B ○、C △、D △。フォーム確認向き。 |
| Alternative names / variants | Double-arm with dolphin kick |

**Focus points（Coach cues）**

- 耳の横へ入水
- 胸を軽く開く
- 水を後ろへ送る

**Common mistakes**

- 腰が反る
- 入水で頭が揺れる
- 水を横へ押す

**Coach use / progression**

- 通常背泳ぎに戻した水感を比較します。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

### 2. Single Arm Back / 片手背泳ぎ

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | 左右差、入水位置、キャッチ深さ。 |
| Description（実施方法・距離目安） | 片腕だけで背泳ぎ。反対腕は体側または上方。25m×左右。 |
| Recommended phase / applicability | A/B ◎、C ○、D △。左右差修正。 |
| Alternative names / variants | One-arm at side/extended |

**Focus points（Coach cues）**

- 頭を固定
- 小指から肩幅へ入水
- 肘を曲げて水を捉える

**Common mistakes**

- 中心線へ入水
- 腕が深すぎる
- キック停止

**Coach use / progression**

- 苦手側は12.5mから始めます。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

### 3. 6-3-6 Back / 6-3-6背泳ぎ

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | ローリング角度と stroke 接続。 |
| Description（実施方法・距離目安） | 6キック、3 stroke、6キックを繰り返す。25〜50m。 |
| Recommended phase / applicability | A/B ◎、C ○、D △。軸作り。 |
| Alternative names / variants | 3-3-3, 6-kick switch |

**Focus points（Coach cues）**

- 鼻先は天井
- 肩と腰を一緒に回す
- キックを継続

**Common mistakes**

- 頭が左右に振れる
- ローリング過大
- 急ぎすぎる

**Coach use / progression**

- 真っすぐ泳げているか lane line を基準に観察。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

### 4. Streamline Kick on Back / 背面ストリームラインキック

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | 姿勢、体幹、キック水面位置。 |
| Description（実施方法・距離目安） | 背面 streamline でキック。25〜50m。 |
| Recommended phase / applicability | A/B ◎、C ○、D ○。Warm-up にも有効。 |

**Common mistakes**

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

### 5. Rotation Drill / ローテーションドリル

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | 体幹からのローリング。 |
| Description（実施方法・距離目安） | 腕を体側に置き左右へ roll しながら kick。25m。 |
| Recommended phase / applicability | A/B ◎、C ○、D △。姿勢基礎。 |
| Alternative names / variants | Shoulder roll kick |

**Focus points（Coach cues）**

- 頭は静かに

- テンポを変えない

**Common mistakes**

- 頭も回る
- 肩だけ動く
- 呼吸が乱れる

**Coach use / progression**

- 蛇行する選手に短い反復で入れます。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

### 6. Catch Drill on Back / 背泳ぎキャッチドリル

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | 入水後に水を逃がす課題。 |
| Description（実施方法・距離目安） | 入水後に一度止め、浅めの catch を確認。25m。 |
| Recommended phase / applicability | A/B ◎、C ○、D △。低速で正確に。 |
| Alternative names / variants | Pause catch back |

**Focus points（Coach cues）**

- 手を深く落としすぎない
- 肩幅を守る
- 頭と腰を水平に

**Common mistakes**

- 止めすぎて沈む
- 下へ押す
- 内側へ入水

**Coach use / progression**

- scull と組み合わせると理解しやすいです。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

### 7. Backstroke Scull / 背泳ぎスカーリング

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | 浅い catch と finish 感覚。 |
| Description（実施方法・距離目安） | 背面で肩横または腰横を sculling。15〜25m。 |
| Recommended phase / applicability | A/B ◎、C ○、D ◎。感覚練習。 |
| Alternative names / variants | Entry/mid/finish scull |

**Focus points（Coach cues）**

- 前腕に水圧
- 腰を沈めない
- 小さい動き

**Common mistakes**

- 大きく掻く
- 泡を作る
- 頭が起きる

**Coach use / progression**

- テーパー中の水感確認に向きます。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

### 8. Tempo Back / テンポ背泳ぎ

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | stroke tempo と kick 同期。 |
| Description（実施方法・距離目安） | 25〜50m で一定 tempo、最後10m build。 |
| Recommended phase / applicability | B ○、C ◎、D ○。race rhythm 作り。 |
| Alternative names / variants | Metronome back |

**Focus points（Coach cues）**

- 入水位置を守る
- 6-beat kick
- 頭を固定

**Common mistakes**

- テンポだけ上げる
- 腕とkickが分離
- 腰が沈む

**Coach use / progression**

- Race pace 前に短く入れます。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

## セットへの組み込み例

- 6-3-6 → Single Arm → Swim で軸と catch を接続。
- Start-turn 練習では Streamline Kick on Back と breakout を組み合わせます。

## Safety / operation

- 痛み、めまい、過呼吸が出る場合は中止します。
- 呼吸制限や水中動作は監視可能な範囲と十分な休息を前提にします。
- ドリル名は標準用語として扱い、選手固有のメモは custom knowledge に分離します。
