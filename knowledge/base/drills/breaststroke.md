# Breaststroke Drills / 平泳ぎドリル

公開配布用のドリルナレッジです。個人名・実在施設名・PII は含めず、`masters group A` や `local pool SCM` のような一般表現だけを使います。

## 参照

- Phase / Zone: `../../references/zone-phase-mapping.md`
- Menu design: `../../references/menu-design.md`
- Drill は良い動作を保てる距離で止め、疲労した反復を増やしません。

## Phase 適用度（共通ガイド）

| Phase | 適用度 | 使い方 |
|---|---:|---|
| A 基礎形成 | ◎ | 低強度で反復し、動作の土台を作る |
| B ビルド | ◎ | Drill + Swim でメインセットへ接続する |
| C レース特異 | ○ | 短距離・高品質でレース動作へ転移する |
| D テーパー | △〜◎ | 疲労を残さない量で感覚確認に使う |

## Coach implementation guide

| 場面 | 入れ方 | 例 |
|---|---|---|
| Warm-up 後 | 25m 単位で導入 | 4 × 25m drill @ easy |
| Pre-main | Drill/Swim で接続 | 6 × 50m drill/swim by 25m |
| Technique day | 低強度で反復 | 8 × 50m, 1 cue only |
| Taper | 少量・高品質 | 4 × 25m, full rest |

## Drill collection

### 1. 2-Kick 1-Pull / 2キック1プル

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | 蹴り終わりの伸び、プルとキックの分離。 |
| Description（実施方法・距離目安） | 1 pull に対して2 kick。25〜50m。 |
| Recommended phase / applicability | A/B ◎、C ○、D △。timing 作り。 |
| Alternative names / variants | Pull-2-kick |

**Focus points（Coach cues）**

- 1回目後に line を整える
- 2回目で長く伸びる
- 呼吸は低く

**Common mistakes**

- 伸びすぎて止まる
- 膝を開きすぎる
- 頭が残る

**Coach use / progression**

- 通常泳に戻し、滑りと stroke count を比較。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

### 2. 3 Kicks Under Water / 水中3キック

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | streamline、kick 方向、足裏の水感。 |
| Description（実施方法・距離目安） | 水中で3回 breast kick 後に浮上。短距離・安全優先。 |
| Recommended phase / applicability | A/B ○、C △、D △。息こらえ過多にしない。 |
| Alternative names / variants | 3-kick glide |

**Focus points（Coach cues）**

- 足を閉じて細い姿勢
- 無理に長く潜らない
- 足裏で後ろへ押す

**Common mistakes**

- 膝が前に出る
- 足首が返らない
- 息を我慢しすぎる

**Coach use / progression**

- 安全管理が難しい場合は背面 kick に置換。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

### 3. Sculling Breast / 平泳ぎスカーリング

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | 外掻き・内掻きの水感。 |
| Description（実施方法・距離目安） | 前方 scull から小さな pull へ。15〜25m。 |
| Recommended phase / applicability | A/B ◎、C ○、D ◎。感覚確認。 |
| Alternative names / variants | In-sweep scull |

**Focus points（Coach cues）**

- 肘を後ろへ引きすぎない
- 前腕に圧
- 泡を少なく

**Common mistakes**

- 大きく広げすぎる
- 肘が落ちる
- 顔を上げたまま

**Coach use / progression**

- D期は scull+swim で水感確認。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

### 4. Fly-kick Breast / バタフライキック平泳ぎ

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | 波動、低い呼吸、前方移動。 |
| Description（実施方法・距離目安） | Breast pull に dolphin kick を合わせる。25m。 |
| Recommended phase / applicability | B ○、C ○、D △。上級者向け。 |
| Alternative names / variants | Dolphin breast |

**Focus points（Coach cues）**

- 胸を前下方へ
- 呼吸は低く
- kick は小さめ

**Common mistakes**

- 腰を反りすぎる
- 上下動が大きい
- pull が大きすぎる

**Coach use / progression**

- 低い呼吸の感覚作りとして短く使用。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

### 5. Delay Drill / ディレイドリル

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | 手が戻る前に kick してしまう課題。 |
| Description（実施方法・距離目安） | 手を前へ戻し切ってから kick。25〜50m。 |
| Recommended phase / applicability | A/B ◎、C ○、D △。timing 修正中心。 |
| Alternative names / variants | Hands-first breast |

**Focus points（Coach cues）**

- 手が揃ってから蹴る
- 頭をすぐ戻す
- 蹴り終わりを長く

**Common mistakes**

- 待ちすぎる
- 戻る途中で膝を引く
- 上体が高い

**Coach use / progression**

- 通常泳と交互にして自然な timing へ戻します。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

### 6. Timing Drill / タイミングドリル

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | Pull-breathe-kick-glide の順序。 |
| Description（実施方法・距離目安） | 声かけや tempo に合わせ 25m。 |
| Recommended phase / applicability | A/B ◎、C ○、D ○。全レベル可。 |
| Alternative names / variants | Call-out timing |

**Focus points（Coach cues）**

- 掻く・吸う・戻す・蹴る
- kick 前に手と頭を戻す
- glide は進む間だけ

**Common mistakes**

- glide 長すぎ
- pull が大きい
- kick 後すぐ掻く

**Coach use / progression**

- ジュニアは言葉の rhythm、上級者は速度と連動。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

### 8. Pull with Buoy / ブイ付き平泳ぎプル

|---|---|
| Purpose（どんな課題に対して） | pull幅、呼吸高さ、前方戻し。 |
| Description（実施方法・距離目安） | Pull buoy を軽く挟み breast pull。25〜50m。 |

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

## セットへの組み込み例

- Delay Drill → Timing Drill → Swim で timing を統合。
- 水中動作は安全と監視を最優先します。

## Safety / operation

- 痛み、めまい、過呼吸が出る場合は中止します。
- 呼吸制限や水中動作は監視可能な範囲と十分な休息を前提にします。
- ドリル名は標準用語として扱い、選手固有のメモは custom knowledge に分離します。
