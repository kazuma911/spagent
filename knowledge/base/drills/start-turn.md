# Start & Turn Drills / スタート・ターンドリル

公開配布用のドリルナレッジです。個人名・実在施設名・PII は含めず、`masters group A` や `local pool SCM` のような一般表現だけを使います。

## 参照

- Phase / Zone: `../../references/zone-phase-mapping.md`
- Menu design: `../../references/menu-design.md`
- Drill は良い動作を保てる距離で止め、疲労した反復を増やしません。

## Phase 適用度（共通ガイド）

| Phase | 適用度 | 使い方 |
|---|---:|---|
| A 基礎形成 | ◎ | 低強度で反復し、動作の土台を作る |
| B ビルド | ◎ | Drill + Swim でメインセットへ接続する |
| C レース特異 | ○ | 短距離・高品質でレース動作へ転移する |
| D テーパー | △〜◎ | 疲労を残さない量で感覚確認に使う |

## Coach implementation guide

| 場面 | 入れ方 | 例 |
|---|---|---|
| Warm-up 後 | 25m 単位で導入 | 4 × 25m drill @ easy |
| Pre-main | Drill/Swim で接続 | 6 × 50m drill/swim by 25m |
| Technique day | 低強度で反復 | 8 × 50m, 1 cue only |
| Taper | 少量・高品質 | 4 × 25m, full rest |

## Drill collection

### 1. Track Start / トラックスタート

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | 反応、前後足の力配分、入水角度。 |
| Description（実施方法・距離目安） | 台または安全な低位置から3〜6本、完全休息。 |
| Recommended phase / applicability | B ○、C ◎、D ◎。race specific。 |
| Alternative names / variants | Wedge start |

**Focus points（Coach cues）**

- 前足で押す
- 跳び上がりすぎない
- 入水後 streamline

**Common mistakes**

- 上へ跳ぶ
- 腕が開く
- 反応だけ急ぐ

**Coach use / progression**

- 施設ルールと安全確認が最優先。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

### 2. Grab Start / グラブスタート

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | 安定構え、両足同時の押し出し。 |
| Description（実施方法・距離目安） | 台前端を握り合図で両足を押す。3〜6本。 |
| Recommended phase / applicability | A/B ○、C ○、D △。導入向き。 |
| Alternative names / variants | Basic grab start |

**Focus points（Coach cues）**

- 合図まで安定
- 細い入水
- 顔を上げない

**Common mistakes**

- 倒れ込むだけ
- 膝が曲がる
- 水中で腕が開く

**Coach use / progression**

- Track start が不安定な選手の比較に使えます。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

### 3. Streamline off Wall / 壁蹴りストリームライン

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | 壁蹴り後の抵抗最小化。 |
| Description（実施方法・距離目安） | 壁から5〜10mまで細い姿勢。6〜10本。 |
| Recommended phase / applicability | A/B ◎、C ◎、D ◎。全期重要。 |
| Alternative names / variants | Push-off glide |

**Focus points（Coach cues）**

- 手を重ねる
- 足先まで一直線
- 失速前に浮上

**Common mistakes**

- 腕が開く
- 腰が反る
- 長く伸びすぎる

**Coach use / progression**

- 毎回の turn 品質向上に warm-up から入れます。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

### 4. Flip Turn Drills / クイックターンドリル

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | 回転速度、壁との距離、蹴り出し方向。 |
| Description（実施方法・距離目安） | 5m approach + turn + 5m breakout。4〜8本。 |
| Recommended phase / applicability | B ◎、C ◎、D ○。race 準備。 |
| Alternative names / variants | Somersault drill |

**Focus points（Coach cues）**

- 小さく回る
- 横向きから押す
- streamline を崩さない

**Common mistakes**

- 近すぎ/遠すぎ
- 膝が開く
- すぐ呼吸する

**Coach use / progression**

- 距離感は個人差があるため一般 cue で指導。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

### 5. Open Turn Drills / オープンターンドリル

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | 両手タッチ、引き寄せ、蹴り出し。 |
| Description（実施方法・距離目安） | 5m approach、両手 touch、横向き streamline。4〜8本。 |
| Recommended phase / applicability | B ◎、C ◎、D ○。stroke specific。 |
| Alternative names / variants | Two-hand touch turn |

**Focus points（Coach cues）**

- 片手を素早く戻す
- compact に回る
- 顔を上げて休まない

**Common mistakes**

- 壁にぶら下がる
- 正面で回る
- 腕が開く

**Coach use / progression**

- Breast/Fly 選手に定期的に入れます。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

### 6. Breakout Drill / ブレイクアウトドリル

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | 水中速度から水上泳への接続。 |
| Description（実施方法・距離目安） | 壁蹴り + 3〜6 underwater kicks + breakout。10〜15m。 |
| Recommended phase / applicability | B ○、C ◎、D ◎。race 前に高品質。 |
| Alternative names / variants | Kick count breakout |

**Focus points（Coach cues）**

- 最初の一掻きを強く
- 頭を上げない
- ルール内で実施

**Common mistakes**

- 潜りすぎて失速
- 浮上で呼吸
- kick 数に固執

**Coach use / progression**

- 最速で浮上できる範囲を探します。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

### 7. Finish Drill / フィニッシュドリル

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | 最後5mの失速防止。 |
| Description（実施方法・距離目安） | 10〜15m から wall へ sprint。4〜8本。 |
| Recommended phase / applicability | C ◎、D ◎。race specific。 |
| Alternative names / variants | No-breath finish |

**Focus points（Coach cues）**

- 最後の呼吸を決める
- 壁へ伸びる
- 安全に停止

**Common mistakes**

- 壁前で流す
- 合わせすぎて失速
- touchで顔を上げる

**Coach use / progression**

- Race simulation の短い quality block に向きます。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

### 8. Relay Exchange Timing / リレー引き継ぎタイミング

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | 安全な踏み切り timing。 |
| Description（実施方法・距離目安） | 架空の前泳者を想定し timing のみ3〜5本。 |
| Recommended phase / applicability | C ○、D ○。必要時のみ。 |
| Alternative names / variants | Dry timing |

**Focus points（Coach cues）**

- 安全ルール優先
- 見てから押す
- 入水後 streamline

**Common mistakes**

- 早く出ることだけ狙う
- 構えが不安定
- 入水後を省く

**Coach use / progression**

- 実在大会名や個人名は使わず generic scenario とします。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

## セットへの組み込み例

- C/D期は量より品質、完全休息。
- 混雑時は start を避け wall push と breakout に置換。

## Safety / operation

- 痛み、めまい、過呼吸が出る場合は中止します。
- 呼吸制限や水中動作は監視可能な範囲と十分な休息を前提にします。
- ドリル名は標準用語として扱い、選手固有のメモは custom knowledge に分離します。
