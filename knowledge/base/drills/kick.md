# Kick Drills / キックドリル

公開配布用のドリルナレッジです。個人名・実在施設名・PII は含めず、`masters group A` や `local pool SCM` のような一般表現だけを使います。

## 参照

- Phase / Zone: `../../references/zone-phase-mapping.md`
- Menu design: `../../references/menu-design.md`
- Drill は良い動作を保てる距離で止め、疲労した反復を増やしません。

## Phase 適用度（共通ガイド）

| Phase | 適用度 | 使い方 |
|---|---:|---|
| A 基礎形成 | ◎ | 低強度で反復し、動作の土台を作る |
| B ビルド | ◎ | Drill + Swim でメインセットへ接続する |
| C レース特異 | ○ | 短距離・高品質でレース動作へ転移する |
| D テーパー | △〜◎ | 疲労を残さない量で感覚確認に使う |

## Coach implementation guide

| 場面 | 入れ方 | 例 |
|---|---|---|
| Warm-up 後 | 25m 単位で導入 | 4 × 25m drill @ easy |
| Pre-main | Drill/Swim で接続 | 6 × 50m drill/swim by 25m |
| Technique day | 低強度で反復 | 8 × 50m, 1 cue only |
| Taper | 少量・高品質 | 4 × 25m, full rest |

## Drill collection

### 1. Vertical Kick / 垂直キック

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | 推進方向、体幹、足首の使い方。 |
| Description（実施方法・距離目安） | 深めの場所で15〜30秒。Free/Fly/Back kick に応用。 |
| Recommended phase / applicability | B ○、C ◎、D △。強度管理。 |
| Alternative names / variants | Hands out vertical kick |

**Focus points（Coach cues）**

- 体幹を長く
- 水を下へ押す
- 短時間高品質

**Common mistakes**

- 自転車漕ぎ
- 肩が力む
- 長くやりすぎる

**Coach use / progression**

- 深さと安全確認ができる環境のみ。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

### 2. Kick on Back Streamline / 背面ストリームラインキック

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | 姿勢抵抗と腰高 kick。 |
| Description（実施方法・距離目安） | 背面 streamline で25〜50m。 |
| Recommended phase / applicability | A/B ◎、C ○、D ○。全泳法の姿勢作り。 |
| Alternative names / variants | Arms side back kick |

**Focus points（Coach cues）**

- 肋骨を締める
- 小さく速い kick
- 腕は耳の後ろ

**Common mistakes**

- 膝が出る
- 腕が開く
- 頭を起こす

**Coach use / progression**

- Warm-up にも入れやすい基本。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

### 3. Board Kick Sprint / 板キックスプリント

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | 脚速度と race 後半の kick 出力。 |
| Description（実施方法・距離目安） | 12.5〜25m sprint、30〜60秒 rest。 |
| Recommended phase / applicability | B ○、C ◎、D ○。量を絞る。 |
| Alternative names / variants | No-board sprint kick |

**Focus points（Coach cues）**

- 足首を柔らかく
- 体幹を固定
- 質が落ちたら終了

**Common mistakes**

- 板を押さえる
- 膝曲げが大きい
- 休息不足

**Coach use / progression**

- C/D期の speed stimulus。脚疲労を残しすぎません。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

### 4. Underwater Dolphin Kick / 水中ドルフィンキック

| 項目 | 内容 |
|---|---|
| Purpose（どんな課題に対して） | start/turn 後の水中速度。 |
| Description（実施方法・距離目安） | 壁蹴り後5〜10m。無理な距離延長は禁止。 |
| Recommended phase / applicability | B ○、C ◎、D ◎。race specific。 |
| Alternative names / variants | UW kick to breakout |

**Focus points（Coach cues）**

- 細い streamline
- 胸から小さな波
- 浮上前に速度維持

**Common mistakes**

- 潜水距離を競う
- 膝を大きく曲げる
- breakout で頭が上がる

**Coach use / progression**

- 息こらえではなく速度と姿勢の drill。

**Suggested micro-set**

- 4 × 25m drill @ easy → 2 × 50m swim with the same cue。

**Suggested micro-set**

## セットへの組み込み例

- Vertical と sprint kick は量を絞り、脚疲労を管理。
- Fin は成功姿勢を作る補助具として使い、外した後を確認。

## Safety / operation

- 痛み、めまい、過呼吸が出る場合は中止します。
- 呼吸制限や水中動作は監視可能な範囲と十分な休息を前提にします。
- ドリル名は標準用語として扱い、選手固有のメモは custom knowledge に分離します。
