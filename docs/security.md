# Security and PII Protection

spagent は個人情報を集める道具ではありません。
タイム、RPE、体調、画像を扱うため、PII 保護を最優先します。

## 用語ミニ辞典

| 用語 | コーチ向け説明 | エンジニア向け説明 |
|---|---|---|
| RPE | 主観的運動強度。1 が楽、10 が限界。 | 人間入力の負荷メトリクス。 |
| PB | 自己ベスト。 | ペース推定の基準値。 |
| LCM | 長水路、50m プール。 | `course = LCM`。 |
| SCM | 短水路、25m プール。 | `course = SCM`。 |
| T-pace | 閾値ペース。少しきついが持続できる速度。 | Threshold の基準。 |
| Phase | 大会までの時期区分。 | A/B/C/D の状態。 |
| Zone | EN1 から SP3 などの強度帯。 | 検索・タグ付け軸。 |
| Method | Threshold, Broken などの練習手法。 | Workflow A で当日選ぶ戦術。 |
| Cycle | 出発間隔。 | interval / send-off。 |
| PII | 個人情報 (Personal Identifiable Information)。 | git に入れない保護対象。 |

## なぜ必要か

練習記録は単体では小さな情報でも、組み合わせると個人を特定できます。
ジュニア選手では本人と保護者の安心が最優先です。
GitHub に誤 push される可能性も前提にします。

## 収集しない情報

- フルネーム。
- 電話。
- メール。
- 住所。
- 生年月日。
- マイナンバー等。
- 学校名、勤務先、実在施設名。
- 顔や名札が写った未承認画像。

## 収集する情報

- エイリアス。
- タイム。
- RPE。
- 体調メモ。
- 練習上の怪我制約。
- 技術課題。
- 承認済み画像。

## 保管場所

| パス | 内容 | 方針 |
|---|---|---|
| `data/` | 選手・グループ・体調 | ローカルのみ |
| `sessions/` | menu/times/feedback/raw | ローカルのみ |
| `plans/` | 長期計画 | ローカルのみ |
| `knowledge/custom/` | コーチ固有知識 | ローカルのみ |

これらは `.gitignore` で除外されています。
手動で `git add -f` しないでください。

## 画像 PII 検知

### 対象

- 顔。
- 名札・胸章。
- ホワイトボード上の実名。
- 背景の施設名。
- Exif GPS。

### 手順

1. raw に置く。
2. Workflow B/G を起動する。
3. 検知結果を確認する。
4. 必要ならマスクする。
5. 承認後に構造化する。

## テキスト PII 検知

### 対象

- 電話番号。
- メール。
- 郵便番号。
- 住所。
- 生年月日。
- ブロックリストの語。

### 手順

1. `python scripts\pii\text_pii_check.py sessions\YYYY-MM-DD\menu.tsv`。
2. 警告箇所を確認する。
3. 匿名化または削除する。

## 同意書テンプレート

### 対象

- 記録目的。
- 撮影目的。
- 保管期間。
- 削除申請方法。
- 共有範囲。

### 手順

1. [../templates/consent-form.template.md](../templates/consent-form.template.md) を使う。
2. ジュニアでは保護者同意を取る。
3. 同意書にも実名を公開しない。

## バックアップ

### 対象

- 暗号化ディスク。
- 外付け HDD。
- 組織承認済みストレージ。

### 手順

1. 定期バックアップする。
2. 媒体を放置しない。
3. 共有リンクの権限を確認する。

## 削除申請

### 対象

- 対象エイリアス。
- data。
- sessions。
- plans。
- custom index。

### 手順

1. 該当行を削除する。
2. バックアップも方針に従って削除する。
3. 完了記録は PII なしで残す。

## 事故時対応

### 対象

- 誤 push。
- 公開範囲拡大。
- Issue への貼り付け。

### 手順

1. リポジトリを private にする。
2. 管理者に連絡する。
3. 該当ファイルを削除する。
4. 必要なら履歴削除を組織ポリシーで実施する。
5. 再発防止する。
