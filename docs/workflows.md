# Workflows

spagent の 7 種の Workflow を詳しく説明します。
authoritative な手順は [../SKILL.md](../SKILL.md) です。

## 用語ミニ辞典

| 用語 | コーチ向け説明 | エンジニア向け説明 |
|---|---|---|
| RPE | 主観的運動強度。1 が楽、10 が限界。 | 人間入力の負荷メトリクス。 |
| PB | 自己ベスト。 | ペース推定の基準値。 |
| LCM | 長水路、50m プール。 | `course = LCM`。 |
| SCM | 短水路、25m プール。 | `course = SCM`。 |
| T-pace | 閾値ペース。少しきついが持続できる速度。 | Threshold の基準。 |
| Phase | 大会までの時期区分。 | A/B/C/D の状態。 |
| Zone | EN1 から SP3 などの強度帯。 | 検索・タグ付け軸。 |
| Method | Threshold, Broken などの練習手法。 | Workflow A で当日選ぶ戦術。 |
| Cycle | 出発間隔。 | interval / send-off。 |
| PII | 個人情報 (Personal Identifiable Information)。 | git に入れない保護対象。 |

## 全体マップ

| Workflow | 目的 | 主な出力 |
|---|---|---|
| A | 練習メニュー作成 | `sessions/YYYY-MM-DD/menu.tsv` |
| B | 記録・フィードバック | `times.tsv`, `feedback.md` |
| C | 索引参照 | 過去メニュー候補 |
| D | 長期プラン | `plans/*.md` |
| E | 初期セットアップ | `data/*.json` |
| F | メンテナンス | custom knowledge |
| G | 取り込み・傾向分析 | 分析と骨格パターン |

## Workflow A: 練習メニュー作成

### 目的

当日の環境、長期計画、選手状態をつなげて 1 回分の練習を作ります。
Phase → Zone → Method → 骨格 → タイム → Cycle の順番を守ることで、現場で回るメニューになります。

### トリガー例

```text
Coach: 明日のメニューを作って。
Coach: 木曜の Threshold で組んで。
Coach: 大会 2 週前なので軽めに。
```
