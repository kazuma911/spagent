# Contributing

spagent への貢献ガイドです。
PII を含まない形で、コーチもエンジニアも貢献できます。

## 想定される貢献

- ドキュメント修正。
- 公式ドリル追加。
- 公式メニューサンプル追加。
- 新しい Method の提案。
- 翻訳。

## 絶対に含めないもの

- 実名。
- 電話。
- メール。
- 住所。
- 生年月日。
- 施設名や学校名。
- 顔や名札の画像。
- 実在選手の体調・怪我詳細。

## Issue の書き方

- 何が起きたか。
- 期待した動作。
- PII を除いた再現手順。
- OS と Python バージョン。

## PR の書き方

- 変更概要。
- なぜ必要か。
- 確認方法。
- PII なしの宣言。

## 公式ナレッジ base/ の追加基準

- 出典明示。
- 複数コーチで検証しやすい。
- PII なし。
- 特定施設に依存しない。
- 安全配慮がある。

## コード規約

- Python は PEP 8。
- 日本語コメント可。
- JSON は snake_case key。
- ファイル名は小文字英数字とハイフン推奨。

## テストについて

- requirements 段階のため未整備。
- 今後追加予定。
- ドキュメントだけなら lint/build 不要。

## 連絡先 / Issues

- GitHub Issues を使う。
- 個人データを貼らない。
- 匿名化した最小サンプルを作る。
- 商用利用や再配布は README 方針に従い相談する。

## Issue テンプレ例

```text
Title: Workflow A の Cycle 説明を改善したい

What happened:
- 初心者コーチに Cycle と rest の違いが伝わりにくい。

Expected:
- 出発間隔として説明し、例を足す。

PII:
- 個人データなし。
```

## PR テンプレ例

```text
Summary:
- docs/training-models.md に Junior の補足を追加。

Validation:
- Markdown の目視確認。

PII:
- 実名、施設名、画像、実データなし。
```
