# 本 Skill は本名を扱いません

この書面は、spagent（Swim Practice Agent）を利用する前に、選手・保護者へ説明し同意を得るためのテンプレートです。実運用ではチーム方針に合わせて追記してください。

## プロジェクト概要

spagent は、水泳コーチが練習メニュー作成、練習記録、振り返り、長期計画作成を補助する GitHub Copilot Skill です。選手は本名ではなく `athlete-001` や `alice` のような匿名 ID / エイリアスで扱います。

## 収集する情報

- 匿名 ID / エイリアス
- 練習・大会のタイム、スプリット、RPE
- 怪我、体調、疲労、欠席などの体調記録
- 技術課題、コーチメモ、AI が推論した傾向（コーチ承認後のみ使用）
- 練習メモ画像（必要な場合のみ。顔・名札などが写る場合はマスクまたは削除します）

## 保管場所

- `data/`: 選手情報、グループ情報、ペース、体調、技術メモなど
- `sessions/`: 日ごとの練習メニュー、タイム、フィードバック、画像素材など
- 上記はローカルのみで保管し、リポジトリには含めません。

## 削除申請の手順

1. 選手または保護者が、コーチへ削除したい情報の範囲を伝えます。
2. コーチは `data/` と `sessions/` から該当する匿名 ID / エイリアスの情報を削除します。
3. 画像がある場合は、元画像と解析済みメモの両方を確認して削除します。
4. 削除後、コーチは削除完了日を記録し、本人または保護者へ通知します。
