## セット内容

```
[1] Swim  1×400 @8'   — Choice / Easy (Z1, DPS 一定)
[2] Drill 6×50 @1'30" — Phase C ルーティン:
      Scull#1 fast / Single-Arm 2-beat R / Single-Arm 2-beat L /
      Dolphin Crawl / Changeover / Swim w/ RP cues
      (fins は 2-4 番で活用可)
[3] Swim  6×50 @50"   — IM-mix: Fly / Fr / Ba / Fr / Br / Fr (moderate)
[4] AP    1×100 @3'   — 腹圧コントロール (v1=buoy 片手キック / v2=buoy 片手 + board 手甲乗せ Fr) ★毎回必須 (§3.4)
[5] Rest  1'
```

**総距離**: 1100m
**目安時間**: 22 min

## 目的・意図

- 試合 2-4 週前 = Peak 直前、RP cue で SR (stroke rate) 感覚を残す
- fast/RP cue 要素を導入して race pace 感覚を neuro に刻む
- Changeover で「入水→キャッチ→フィニッシュ」の連動精度

## Phase C ドリル解説

- **Scull#1 fast**: キャッチ位置固定を fast tempo で
- **Single-Arm 2-beat R/L**: 片手 + 2-beat kick (Phase B 継承だが tempo up)
- **Dolphin Crawl**: 高肘 catch → 対側 down-kick の連続 (推進タイミング)
- **Changeover**: catch → finish → 反対手入水の切替精度
- **Swim w/ RP cues**: RP 感覚で 50 (SR = race pace の SR)

## 適用場面

- 試合まで 2-4 週
- Peak phase 導入 (RP 導入直後含む)
- athlete-b (D-34, Trans) のような Trans→Peak 移行選手にも適用可

## AP 腹圧統合 (§3.4) ★組込済

上記 [4] に統合済み。従来「別ブロックで技術帯に置く」形式から本テンプレは W-up 内統合形式。

## 非推奨

- 試合 0-2 週 (Race week 含む) → `spa-fixed-phaseD-taper` を使う
- 試合 4 週以上 → `spa-fixed-phaseB-1000` を使う
