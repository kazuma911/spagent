## セット内容

```
200 easy choice (Fr/Ba/Br 任意, HR 上げ過ぎない)
4×50 Drill/Swim by 25 @ 1:10 (catch-up / DPS / 6-kick 等)
4×25 build to EN2 @ 0:40
```

**総距離**: 400m
**目安時間**: 8 min (transition 込み 9-10 min)

## 目的・意図

- 神経・関節・呼吸を Main Zone に接続する
- Drill で当日の技術テーマ (catch / stroke length / kick) を刺激
- Build で EN2 の pace 感覚を体に入れる (Main の Threshold/Descending の入りをスムーズに)

## 適用場面

- 標準的な 90-150 min 練習
- Main が Threshold, Descending, Broken の日
- gear 0 (通常) または gear -1 (軽疲労)

## 非推奨

- gear -2/-3 (疲労大) — `scm-recovery-300` を使う
- レース前日 taper — `lcm-race-taper-300` (LCM) や短縮版を使う
