## セット内容

```
[1] Swim  1×400 @8'   — Choice / Easy (Z1, DPS 一定)
[2] Drill 6×50 @1'15" — Phase B ルーティン:
      3-position Scull / Doggy / Single-Arm 2-beat R / Single-Arm 2-beat L /
      Catch-up→FQ / Swim w/ cues
      (fins は 3-5 番で活用可)
[3] Swim  6×50 @50"   — IM-mix: Fly / Fr / Ba / Fr / Br / Fr (moderate)
[4] AP    1×100 @3'   — 腹圧コントロール (v1=buoy 片手キック / v2=buoy 片手 + board 手甲乗せ Fr) ★毎回必須 (§3.4)
[5] Rest  1'
```

**総距離**: 1100m
**目安時間**: 21 min (Drill cycle 1'30"→1'15" 短縮反映)

## 目的・意図

- 試合 4-8 週前 = base → race pace 移行の中間期
- Single-Arm 系で片側キャッチとローテーション矯正
- Catch-up → FQ で catch のタイミング切替

## Phase B ドリル解説

- **3-position Scull**: 前方 / 中間 / 後方の 3 ポジションで水感 (キャッチ経路の理解)
- **Doggy**: 高肘 catch 極端強調 (base 継承)
- **Single-Arm 2-beat R/L**: 片手で 2-beat kick、ローテーション + 呼吸タイミング
- **Catch-up → FQ**: catch-up で長さ確保 → front-quadrant で入水位置意識
- **Swim w/ cues**: 統合、コーチ cue で 1 点集中

## 適用場面

- 試合まで 4-8 週
- Acc-Trans 中間期
- gear 0 (通常) または gear -1 (軽疲労)

## AP 腹圧統合 (§3.4) ★組込済

上記 [4] に統合済み。従来「別ブロックで技術帯に置く」形式から本テンプレは W-up 内統合形式。

## 非推奨

- 試合 2-4 週 → `spa-fixed-phaseC-1000` を使う
- gear -2/-3 → `scm-recovery-300` を使う
