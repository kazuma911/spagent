## セット内容

```
[1] Swim  1×400 @8'   — Choice / Easy (Z1, DPS 一定)
[2] Drill 6×50 @1'30" — Phase A ルーティン:
      Scull#1 / Doggy / Fist / 6-3-6 / Streamline Kick / Swim w/ cues
      (fins は 3-5 番で活用可)
[3] Swim  6×50 @50"   — IM-mix: Fly / Fr / Ba / Fr / Br / Fr (moderate)
[4] AP    1×100 @3'   — 腹圧コントロール (v1=buoy 片手キック / v2=buoy 片手 + board 手甲乗せ Fr) ★毎回必須 (§3.4)
[5] Rest  1'
```

**総距離**: 1100m
**目安時間**: 22 min

## 目的・意図

- Easy + 🔁 ドリルルーティン + IM-mix を 1 ブロックに統合 (別ラベルには分けない)
- 力み取る / 高肘 catch / 腹圧で体幹固定 / DPS 一定
- 試合が遠いフェーズ = base 動作の反復重視

## Phase A ドリル解説

- **Scull#1**: 水キャッチの手位置固定 (前腕垂直)
- **Doggy**: 高肘 catch を極端に強調
- **Fist**: 掌なしで前腕面での水押し感覚
- **6-3-6**: サイド 6 キック → 3 stroke → 反対サイド (ローテーション意識)
- **Streamline Kick**: 姿勢 + キック推進
- **Swim w/ cues**: 全体統合、コーチ cue で 1 点集中

## 適用場面

- 試合まで 8 週以上 (または試合予定なし)
- Acc 期 base building
- gear 0 (通常) または gear -1 (軽疲労)

## AP 腹圧統合 (§3.4) ★組込済

上記 [4] に統合済み。従来「別ブロックで技術帯に置く」形式から本テンプレは W-up 内統合形式。

## 非推奨

- 試合 8 週以内 → `spa-fixed-phaseB-1000` 以降を使う
- gear -2/-3 (レース翌日等) → `scm-recovery-300` を使う
